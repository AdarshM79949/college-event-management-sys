# UI UX Pro Max Skill

A complete design intelligence skill for creating modern, award-winning user interfaces.

## Core Design Rules
1. **Curated Color Tokens**:
   - Primary: `#6366f1` (Electric Indigo), `#a855f7` (Cyber Violet).
   - Accents: `#06b6d4` (Cyan), `#10b981` (Emerald Success), `#f59e0b` (Amber Warning), `#f43f5e` (Rose Danger).
   - Theme switching: Full support for Dark Zinc and Crisp Light Frosted Glass.

2. **Typography Hierarchy**:
   - Display: `Space Grotesk`, `Outfit`, or `Plus Jakarta Sans`.
   - Modifiers: Uppercase letter-spacing `0.06em` to `0.08em` for badges and tags.

3. **Motion & Interaction**:
   - Hover transformations: `translateY(-4px)` with shadow expansion.
   - Ripple and pulse keyframe animations on active statuses.
   - Celebration particle effects (confetti) on critical user conversions (ticket booking).
