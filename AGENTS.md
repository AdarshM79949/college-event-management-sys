# Workspace Agent Configuration - CampusPulse

## Project Overview
**CampusPulse** is an enterprise-grade College Event Management System with role-based features for:
1. **Students**: Event discovery, multi-filter search, ticket RSVP & booking, QR badge generation, personalized schedule, and feedback.
2. **Organizers**: Event wizard with timeline & ticket tiering, real-time attendee management, QR check-in scanner simulator, and analytics.
3. **Admins / Faculty**: Venue conflict management, event approval workflows, and campus-wide metrics.
